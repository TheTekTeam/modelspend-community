# Contributing and feedback

ModelSpend Community is **free-to-use proprietary software**, not an open-source source distribution. The canonical development repository and commercial plugin implementations remain private.

## Issues

Public issues are welcome for:

- Installation and documentation errors in officially published releases
- Reproducible Core defects with exact version and environment details
- Feature suggestions and interoperability requests

Avoid sharing credentials, private logs, prompt/response content, customer data, or security vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) for security reports.

## Pull requests

This repository is a distribution and documentation surface, **not a parallel application development repository**. Please do not submit copies of application source code, reverse-engineered binaries or commercial plugin implementations. Documentation corrections may be suggested through issues; maintainers will decide how to incorporate them.

## Official status

Only separately designated, reviewed artifacts on official release pages count as ModelSpend Core distributions. GitHub-generated source archives contain this public repository's documentation, **not the ModelSpend application**. See [RELEASES.md](RELEASES.md).
