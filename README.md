# ModelSpend Community

**Free, self-hosted AI routing and spend management.**

ModelSpend is an AI routing and financial management platform developed by **Twizu**.

This repository is the official public home for ModelSpend Community, providing product information, documentation, installation guidance and free self-hosted release distributions.

## Editions

- **ModelSpend Community** — Free, self-hosted core software.
- **ModelSpend Licensed Plugins** — Optional commercial extensions for advanced functionality.
- **ModelSpend Cloud** — A commercial, fully managed SaaS offering.

## Availability

The Community release is being prepared. Verified installation packages and instructions will be published here when available.

The underlying canonical development repository remains private. This repository does not provide the ModelSpend application source code.
