# Security policy

## Reporting a vulnerability

Please **do not disclose security vulnerabilities through public GitHub issues**, pull requests or discussions.

Use GitHub's **Report a vulnerability** / private vulnerability reporting feature on this repository **if the option is available**. Otherwise use the official contact channel listed on [modelspend.best](https://modelspend.best) and request a confidential security-reporting route before sharing sensitive exploit details.

Never include real API keys, tokens, customer information, tenant data, credentials or exploit payloads in public messages.

## Supported releases

Officially supported versions and security-update information will be stated in individual release notes. **No verified public Core package has been published through this repository yet.** Security fixes to a shipped Core release will be distributed only as qualified official artifacts.

## Scope

Reports concerning the free self-hosted ModelSpend Core, release packages and install documentation are welcome. Commercial plugins and the hosted service may have separate security handling and contractual support commitments.

Please provide a concise description, affected version, reproduction steps using non-sensitive test data and potential impact through the confidential channel.
